# Cats Untitled

A browser game: play as one of two black cats in their old house and nap on contested spots to score.

```bash
pnpm install
pnpm dev      # play locally
pnpm check    # types, lint, format, tests
pnpm build    # static site in dist/
```

- Plan and milestones: `docs/plan.md`
- Tunable numbers (speeds, round length, scores): `config.toml`
- House layout: `src/house/mainFloor.ts`
- Asset sources: `docs/credits.md`
